# SecureFlow

Bilingual cybersecurity SaaS landing page built with React, Vite and Tailwind CSS.

## Features

- English / Russian language switch with saved preference
- Responsive layout for desktop, tablet and mobile
- Security dashboard mockup, feature grid, workflow, pricing and FAQ
- Client-side contact form validation and success state
- Subtle scroll reveal and hover interactions
- Reduced-motion accessibility support
- Production build via Vite

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
