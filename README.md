# SecureFlow

Modern bilingual cybersecurity SaaS landing page built with React, Vite and Tailwind CSS.

## Live Demo

https://secureflow-landing-page.vercel.app

## Overview

SecureFlow is a responsive cybersecurity SaaS landing page created as a portfolio project.

The project demonstrates modern frontend development, responsive UI design, reusable React components and bilingual interface support.

## Features

- Responsive desktop and mobile layout
- English / Russian language switch
- Modern cybersecurity SaaS design
- Hero section
- Product features
- Platform overview
- Pricing plans
- FAQ section
- Contact form UI with client-side validation
- Reusable React components
- Production-ready Vite build
- Deployment with Vercel

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- Lucide React
- Vercel

## Local Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```

## Production Build

Create a production build:

```bash
npm run build
```

The production files will be generated in:

```text
dist/
```

## Deployment

The project is deployed on Vercel.
